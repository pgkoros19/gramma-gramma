# Γράμμα Γράμμα

Ηλεκτρονικός ελληνικός γραμματοπίνακας για μαθητές που επικοινωνούν δείχνοντας γράμματα.

Δημιουργία: **Πέτρος Γκόρος** · © 2026

**Μόνο για εκπαιδευτικούς σκοπούς.** Δεν είναι ιατροτεχνολογικό προϊόν και δεν αντικαθιστά την αξιολόγηση ή την καθοδήγηση από ειδικό. Δεν συνδέεται με κανέναν οργανισμό ή δημιουργό μεθόδου επικοινωνίας. Οι πλήρεις όροι είναι στο [NOTICE.md](NOTICE.md).

Τι περιέχει:

- **Στένσιλ** με 4, 8 ή 12 γράμματα, **πλήρη πίνακα** και **πληκτρολόγιο**
- Εκφώνηση γραμμάτων και λέξεων, πρόβλεψη λέξεων και αυτόματο κενό
- Πίνακες για αριθμούς, Ναι / Όχι, συναισθήματα, πόνο, επιλογές και φράσεις
- Μαθήματα με ερωτήσεις, βαθμολόγιο, πρόοδο και αναφορές PDF
- Πολλούς μαθητές, κλείδωμα ελέγχων και οθόνη διαλείμματος
- Λειτουργία χωρίς internet, αφού ανοίξει μία φορά

Όλα τα δεδομένα μένουν στη συσκευή όπου γράφτηκαν. Η εφαρμογή δεν στέλνει τίποτα σε κάποιον server.

## Ανέβασμα στο GitHub Pages (δωρεάν)

### 1. Λογαριασμός

Αν δεν έχεις, φτιάξε λογαριασμό στο <https://github.com/signup>.

### 2. Νέο repository

1. Πάτα το **+** πάνω δεξιά και μετά **New repository**.
2. Στο **Repository name** γράψε `gramma-gramma`.
3. Διάλεξε **Public**. Η δωρεάν φιλοξενία σελίδων δουλεύει μόνο σε δημόσια repositories. Δημόσιος είναι μόνο ο κώδικας της εφαρμογής, όχι τα δεδομένα των μαθητών.
4. Άφησε όλες τις άλλες επιλογές όπως είναι και πάτα **Create repository**.

### 3. Ανέβασμα των αρχείων

1. Στη σελίδα του νέου repository πάτα τον σύνδεσμο **uploading an existing file**.
2. Άνοιξε τον φάκελο `gramma-gramma-github` στον υπολογιστή σου, επίλεξε **όλα τα περιεχόμενά του** (Ctrl+A) και σύρε τα στη σελίδα. Σύρε τα περιεχόμενα, όχι τον ίδιο τον φάκελο.
3. Έλεγξε ότι ανέβηκαν όλα:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - `.nojekyll`
   - `README.md`
   - `NOTICE.md`
   - ο φάκελος `icons` με 6 αρχεία μέσα
   - ο φάκελος `fonts` με 7 αρχεία μέσα (γραμματοσειρές και οι άδειές τους)
4. Κάτω κάτω πάτα **Commit changes**.

### 4. Ενεργοποίηση της σελίδας

1. Στο repository πάτα **Settings** και αριστερά **Pages**.
2. Στο **Source** διάλεξε **Deploy from a branch**.
3. Στο **Branch** διάλεξε `main` και φάκελο `/ (root)`, και πάτα **Save**.
4. Περίμενε 1–2 λεπτά και ανανέωσε τη σελίδα. Πάνω θα εμφανιστεί η διεύθυνση της εφαρμογής:

   `https://ΤΟ-ΟΝΟΜΑ-ΣΟΥ.github.io/gramma-gramma/`

Αυτόν τον σύνδεσμο μπορείς να τον στείλεις σε όποιον θέλεις. Δεν χρειάζεται λογαριασμό για να τον ανοίξει.

## Στην ταμπλέτα, σαν κανονική εφαρμογή

- **iPad / iPhone (Safari):** άνοιξε τον σύνδεσμο, πάτα το κουμπί Κοινοποίηση (τετράγωνο με βέλος) και διάλεξε **Προσθήκη στην οθόνη Αφετηρίας**.
- **Android (Chrome):** άνοιξε τον σύνδεσμο, πάτα το μενού ⋮ και διάλεξε **Εγκατάσταση εφαρμογής** ή **Προσθήκη στην αρχική οθόνη**.
- **Υπολογιστής (Chrome ή Edge):** πάτα το εικονίδιο εγκατάστασης στη γραμμή διευθύνσεων.

Η εφαρμογή ανοίγει τότε σε πλήρη οθόνη με δικό της εικονίδιο. Μετά το πρώτο άνοιγμα δουλεύει και χωρίς internet. Οι φωνές «Αθηνά» και «Νέστορας» του Microsoft Edge είναι εξαίρεση, γιατί χρειάζονται σύνδεση.

## Μεταφορά δεδομένων από άλλη συσκευή ή από το claude.ai

Κάθε συσκευή και κάθε διεύθυνση κρατά τα δικά της δεδομένα. Για να μεταφέρεις μαθητές, μαθήματα και ιστορικό:

1. Στην παλιά συσκευή: **Πρόοδος → Αντίγραφο ασφαλείας**. Αποθηκεύεται ένα αρχείο `.json`.
2. Στείλε το αρχείο στη νέα συσκευή, για παράδειγμα με email.
3. Στη νέα συσκευή: **Πρόοδος → Επαναφορά από αρχείο** και διάλεξε το αρχείο.

Η επαναφορά αντικαθιστά ό,τι υπάρχει ήδη στη νέα συσκευή.

## Ενημέρωση της εφαρμογής

Όταν υπάρχει νέα έκδοση του `index.html`:

1. Στο repository πάτα **Add file → Upload files**.
2. Σύρε το νέο `index.html` και πάτα **Commit changes**.

Οι συσκευές παίρνουν τη νέα έκδοση την επόμενη φορά που ανοίγουν την εφαρμογή με internet. Τα δεδομένα των μαθητών δεν χάνονται.

```bash
cd gramma-gramma

```

## Τι διαφέρει από την έκδοση στο claude.ai

Λείπει μόνο το κουμπί **«Με βοήθεια AI»** στα Μαθήματα, γιατί χρειάζεται λογαριασμό Claude. Όλα τα υπόλοιπα, μαζί με τα PDF και τα CSV, λειτουργούν κανονικά.

Οι γραμματοσειρές είναι μέσα στην εφαρμογή, στον φάκελο `fonts`. Τα εργαλεία PDF φορτώνουν από το cdnjs την πρώτη φορά που φτιάχνεται PDF και μετά αποθηκεύονται στη συσκευή.
